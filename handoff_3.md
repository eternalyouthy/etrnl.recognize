## Жёсткие правила (сводные)
1. **Языки.** Интерфейс всегда английский. Учебный контент (значения, переводы примеров, объяснения, подсказки, промпты для ролевой игры) идёт на языке «I know». Русские бейджи значений (`МНОГОЗНАЧНОЕ`, `ПЕРЕНОСНОЕ`, `РАЗГОВОРНОЕ`, `СМЫСЛ УШЁЛ`) при «I know: English/German» автоматически показываются как `POLYSEMOUS / FIGURATIVE / COLLOQUIAL / MEANING DRIFTED` или по-немецки.
2. **Без сборки и сервера.** Работает по двойному клику (`file://`) и на статическом хостинге (Netlify Drop). Никакого `fetch` для данных — только `<script>`. Vanilla JS. После любых изменений **поднимать `VERSION` в `sw.js`** (сейчас `etrnl-v27`).
3. **Дизайн не менять:** void black `#04060A`, navy `#0B1A33`, ice `#8CCBFF`, Space Grotesk / Inter / JetBrains Mono, 1px линии, созвездие, нижняя навигация на мобильном, выдвижная панель Settings.
4. **TTS.** Эвристика `pickVoice()` (`/natural|online|google|premium|enhanced/i` + регион) сохранена и параметризована языком; немецкая ветка (`/^de/`, `/de[-_]DE/`) идентична исходной. `#voiceSelect`, Test↔Stop и кнопки озвучки не ломать.
5. **ID постоянные.** Прогресс хранится по ID (`<id>#rec`, `<id>#prod`, у упражнений — `<id>`). Никогда не переименовывать и не пересоздавать ID, не сбрасывать прогресс.
6. **Точность контента.** Правила из `handoff_de 2.md` (раздел 6) действуют для всех языков: разделять морфологию, историческую этимологию, прозрачность и тип значения; мнемонику помечать как мнемонику; `why` — только с `confidence: high|medium`, `source`, `evidence` уровня DWDS/Pfeifer, Wiktionary, OED, Фасмер; `meaningType` — только курированный, всегда с `meaningExplanation` и `meaningExamples`.
7. **Немецкий B1** — только из Goethe-Zertifikat B1 Wortliste (попросить у пользователя PDF). B2-темы, Professional, идиомы и фразы — курируемые.
8. **Английский каталог** (`english/data/*.js`) редактируется в своём формате (ETEnglish) и не копируется; в движок его переводит `js/packs/en.js`.

## Окружение
- Windows, использовать `py` (не `python`), **`node` не установлен**. Сложный Python писать в файлы-скрипты, а не в `py -c`.
- В Git Bash heredoc'и съедают обратные слэши: строки с `\u0301`, `\\s` и т. п. вставлять через Write-скрипт (`chr(92)`), а не через `cat <<EOF`.
- Сервер: `.claude/launch.json` → `wortschatz` (порт 8765). `python -m http.server` отдаёт файлы с эвристическим HTTP-кэшем: после правок делать `fetch(file, {cache:'reload'})` для изменённых файлов или обновлять SW. SW (`etrnl-v24`) уже сверяет файлы с сервером (`cache: 'no-cache'`).
- Встроенный браузер показывает `file://` как статичный снимок без JS — проверка по двойному клику возможна только в обычном Chrome пользователя (с его разрешения).
- localStorage на `http://localhost:8765` — тестовый, изначально пустой. После тестов удалять свои ключи (`etrnl.settings.v1`, `gt.progress.v1`, `etrnl.progress.en.v1`, `etrnl.progress.ru.v1`, `etrnl.english.progress.v1`, `gt.theme`). Реальный прогресс пользователя — на `file://` или Netlify, его не трогать.

## Архитектура (кратко, подробно — README.md)
- **Один движок, языковые пакеты.** `GT.packs.de / en / ru`. `GT.items`, `GT.byId`, `GT.TOPICS`, `GT.roots`, `GT.NAV` … — геттеры активного пакета, поэтому представления не ветвятся по языку. Отличия пакетов — флаги в config: `features.prefixDrill`, `features.rootMapVerbs`, `features.goetheB1`, `nounHint`, `levelName`, `intro`, `NAV`, `PRO_SUBS`, `ROOT_PLAN`, `PREFIX_PLAN`, `baseKnown`.
- **Загрузка.** `index.html` грузит только движок; `GT.loadPack(lang)` (`js/loader.js`) подгружает файлы пакета из `data/manifest.js → GT_PACKS[lang]` по требованию, потом `GT.validatePack` и `config.afterLoad`.
- **Модель данных.** `t` — текст на изучаемом языке (в немецких файлах исторически `de`, на загрузке алиасится в `t`). Глоссы по коду языка: `ru` / `en` / `de` → `GT.gl(obj)`. Объяснения — строка на базовом языке пакета или `{ en, de }`, плюс оверлеи `obj.i18n[lang][field]` → `GT.lx(obj, field)`. Если перевода нет — показывается оригинал с пометкой `RU` (`fbTag`).
- **Членство в темах:** `it.memberOf['tab.topic']`, `alsoIn: [['it','security']]` — одна карточка, общий прогресс.
- **Хранение:** настройки (в т. ч. пара языков) — `etrnl.settings.v1`; прогресс по изучаемому языку — `gt.progress.v1` (de, формат не менялся), `etrnl.progress.en.v1`, `etrnl.progress.ru.v1`. Старый английский прогресс (`etrnl.english.progress.v1`) конвертируется в FSRS один раз. Экспорт — все языки одним файлом; импорт понимает новый формат, старые немецкие и старые английские экспорты.
- **Попап языков:** кнопка-глобус в шапке. Смена «I know» перерисовывает экран на месте (сессии и прокрутка сохраняются). Смена «I learn» оставляет тот же маршрут, сессия языка восстанавливается при возврате; несуществующий маршрут заменяется ближайшим разделом. Консоль: `GT.setLanguages('learn','ru')`.
- **Русское ударение:** в данных `+` перед ударной гласной (`говор+ить`), на загрузке → `\u0301`. На экране ударение рисует CSS (`.stress`, `decorateStress` в `app.js`), т. к. в веб-шрифтах U+0301 лежит в другом сабсете. Озвучка и проверка ответов ударения игнорируют; `ё` = `е` при проверке.
